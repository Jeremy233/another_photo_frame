# 内置素材

内置水印用到的品牌 logo 和胶卷图标。界面草案在 `docs/design/mockups/builtin-watermarks.html`。

- `cameras/`：相机品牌 logo，每个品牌一个文件夹。`brands.json` 列出每个品牌的显示名、EXIF 匹配规则和对应文件；来源和处理方式见 `cameras/SOURCES.md`。
- `films/`：胶卷图标，按胶片厂分文件夹。`films.json` 列出每种胶卷对应的图标；来源、字体和重新生成的方法见 `films/SOURCES.md`。

## 商标

品牌 logo、品牌名和胶卷名是各公司的商标，不在本项目的 GPL 许可范围内，只用于标示拍摄器材和胶卷。扁平胶卷图标的版式和图形是本项目自己画的，按 GPL 发布，但上面的胶卷名和品牌名仍是商标。
