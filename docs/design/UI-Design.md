> 标记：**【已确定】** = 已讨论确认；**【建议】** = 目前方案，可调整；**【待确认】** = 还需决定。
> 产品规范见 `PhotoFrame_V1_Specification.md`。

# 1. 左侧边栏开关

控制左侧边栏显示隐藏。【已确定】

- 位于顶栏左侧、交通灯右边，使用系统标准的侧栏按钮。
- 快捷键 ⌃⌘S（系统默认）。

# 2. 主界面显示切换

切换软件界面，一共三个界面。【已确定】位于顶栏中间，和交通灯同一级，参照 Compressor 的「当前 | 活跃 | 已完成」。

1. **当前**：添加源图、应用预设、调整导出设定、预览、添加导出任务。
2. **活跃**：批量处理进度显示。列出正在执行和排队中的任务，可以暂停、取消。状态列参照 Compressor 写「等待 / 处理中 · 阶段 / 成功 / 失败 / 已取消」。
3. **已完成**：导出历史。列出每个任务的输出文件、尺寸、警告和耗时；可以在 Finder 中显示、重新导出、重试失败的任务。

# 3. 右侧边栏开关

控制右侧边栏显示隐藏。【已确定】

- 位于顶栏右侧，使用系统标准的 Inspector 按钮。
- 快捷键 ⌥⌘I（建议，与系统 Inspector 习惯一致）。
- 界面上的文字（工具栏、菜单、提示）一律叫「右栏」；Inspector 只用在代码和设计文档里。

# 4. 左侧边栏功能切换

切换功能，一共三个功能。【已确定】

- **预设 | 位置 | 素材**，用分段控件切换。
- 详细内容见第 7 节。

# 5. 主界面功能切换

【已确定】V1 不做这个切换按钮。

- Compressor 在这里是「批处理 | 监视文件夹」。
- 「监视文件夹」（Lightroom 等软件导出到某个文件夹后，自动套用预设并输出）适合本软件，但 V1 不做，留到以后的版本。
- 到时候在这个位置加入「批处理 | 监视文件夹」切换。

# 6. 右侧功能栏功能切换

【已确定】右栏分四个标签：**画布 | 全景 | 图层 | 输出**。

- 选中**源图**时：右栏显示原图信息（尺寸、ICC、EXIF、是否 HDR），不显示这四个标签。
- 选中**任务**时：显示这四个标签，修改的是这个任务的参数。
- 选中**多个任务**时：只显示可以批量修改的共同字段，不同值显示为「多个值」。
- 选中**左栏的预设**时：编辑预设本身。
- 改动任务参数不会自动写回预设；需要点「存储为预设」。

# 7. 左侧功能

1. **软件输出预设**：针对不同社交软件的 resize、裁切比例、padded background 等。所有参数在右侧边栏定义完成后保存到左边。
   - 分组：内置、用户保存、导入（从网络分享导入或本地导入），各组之间用分割线隔开。
   - 操作：新建、复制、重命名、删除、导入、导出（`.photoframe`）。
   - 把预设拖到源图或任务列表上，就为该源图创建导出任务。
2. **输出位置**：与 Compressor 类似，用户可以自定义常用的保存路径。左栏标签、底栏、任务列表的列标题用短名「位置」，右栏和提示里用「输出位置」；图层贴在画面哪里叫「锚点」，不叫位置。
   - 每个位置有名称和路径；可以设为默认位置。
   - 把位置拖到任务上，就改变这个任务的输出位置。
3. **素材**：签名、水印、相机图标等本地素材。【暂定】
   - 支持「仅文字」和「图标预览」两种显示方式切换。
   - 按类型分组：签名、水印、相机图标。
   - 把素材拖到右栏「图层」里的素材槽（「素材」一行）上即可绑定。
   - 支持 PNG 和受限 SVG（规范 D-09）。

# 8. 右侧功能

按第 6 节的四个标签分组。

1. **画布**
   - 尺寸 / 比例（resize）
   - 适配方式：完整嵌入（默认）或比例裁切（可选，预览中显示裁切范围）
   - 背景色（pad background，默认 `#FAFAF8`）
   - 最小边距（默认 60 px）
   - 对齐方式
2. **全景**
   - 全景分割开关
   - 切片张数：自动（默认）或手动
   - 上下边距（默认 0）
   - 显示接缝位置（只在预览中显示）
3. **图层**
   - 水印 / 签名：开关、文字或素材、锚点、偏移、不透明度。分节标题用添加时选的名字（「水印」「签名 2」），不显示图层 ID
   - 相机图标：开关、素材、按 EXIF 自动匹配、大小、位置
   - EXIF 文字：显示哪些字段、字体样式
   - 显示在哪些页：仅封面（默认）、所有页、指定页
   - 素材绑定：每个素材槽绑定到哪个本地素材，未绑定时显示提示；绑定来自哪一级写「单任务 / 预设本地 / 用户默认」（D-14）
4. **输出**
   - 格式：JPEG（默认）、PNG
   - 质量（默认最高）
   - 动态范围：SDR / HDR
   - 元数据：保留拍摄参数、保留 GPS（旁边显示隐私警告），默认都不保留
   - 文件命名规则
   - 输出位置

# 9. 主界面功能显示

「当前」界面的上半部分是**预览区**。【已确定】预览放在中间栏上方，参照 Compressor。

- 显示选中任务的成品预览，由后端渲染，和导出结果一致。
- 预览上方可以切换：封面、切片 1…N、全景长卷（显示所有切片和接缝）。
- 缩放：适合窗口、100%、手动缩放；双击打开大图。
- 可以切换「原图 / 成品」对比，以及「SDR / HDR」预览。
- 预览区和任务列表之间的分隔线可以上下拖动。

# 10. 任务列表

「当前」界面的下半部分是**任务列表**。【建议】

- 按源图分组：每张源图下面列出它的导出任务（一个预设一个任务）。
- 每个任务显示：预设名称、输出（尺寸和页数，页数含封面，例如「1080 × 1440 · 4 页」；「张」只用于切片）、输出位置、警告图标（如素材缺失、色彩警告）。
- 从 Finder 进来时叫「图片」（「添加图片…」），进入批次后叫「源图」。
- 从 Finder 拖入图片即可添加源图；把预设拖到源图上即可添加任务。
- 支持多选、删除、复制任务。

# 11. 批处理进度条

【建议】

- 位于底栏，显示整个批处理的总进度。
- 按真实进度计算（已完成的输出文件数和阶段），不显示假的匀速进度。
- 每个任务的详细进度在「活跃」界面里显示。

# 12. 底栏

【待确认】参照 Compressor，底栏放全局操作：

- 添加图片按钮
- 默认输出位置（「位置」下拉菜单，选左栏「位置」里的一项）
- 批处理进度条（第 11 节）
- 开始批处理按钮
